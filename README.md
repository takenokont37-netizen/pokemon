# ポケモンチャンピオンズ 構築メモ（ニンフィア軸）

このリポジトリは、ポケモンチャンピオンズのシングルバトル構築を
リサーチ・検討するための作業メモです。リモートセッションに引き継ぐ用。

## 注意（重要）
- 過去のセッションで他世代のポケモン（トドロクツキ、トゲキッスなど）を
  誤って「環境上位」として記載してしまったが、**これらはポケモンチャンピオンズに
  内定（実装）されていない**ため、構築候補から削除した。
- 以下に記載するポケモンは、各種攻略サイト（ゲームウィズ／アルテマ／ゲームエイト／
  ポケモン徹底攻略）で「内定ポケモン一覧」に掲載されていることを個別に検索確認したもののみ。
  未確認のポケモンは「要確認」として明記する。

## ファイル構成
- `meta-tier-notes.md` … 環境上位ポケモンのメモ（内定確認済みのみ）
- `nymphia-build.md` … ニンフィアの育成論
- `team-draft.md` … 構築案（ドラフト、未完成）
- `todo.md` … 次にやること
